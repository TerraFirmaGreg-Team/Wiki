Fenced code with `title`, `lineNumbers` and line highlight (`{1,3}`) meta. Inline code works too: `const x = 1`. The `title` meta is where to surface the language/file name; common languages are highlighted (js/ts, java, json, yaml, bash, md, toml, diff).
