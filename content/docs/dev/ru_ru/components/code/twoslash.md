`ts twoslash` запускает анализ TypeScript для блока на этапе сборки:

- наведение на токен — попап с типом и JSDoc
- `^?` под токеном — выводит тип инлайн под строкой
- `^|` под позицией — выводит список автодополнений
- `^^^` под символами — подсвечивает их
- `// @errors: 2322` — объявляет ожидаемые ошибки (волнистое подчёркивание + строка ошибки)
- `// @log:`, `// @warn:`, `// @annotate:` — аннотационные строки с иконками
- `// ---cut---` — скрывает всё выше маркера (импорты, boilerplate)
- `// @filename:` / `// @<флаг-tsconfig>` — виртуальные файлы и опции компилятора
