### Changes
- GTCEu ores got a new id — this means ore in old worlds will be wiped, such is the way, but thanks to this we managed to remove vanilla and a bunch of other GTCEu ore types, which will improve game performance.
- Any GTCEu ore is now shown on the processing diagram.
- Fixed a rare crash with SimpeLogin.
- Replaced TFC stone tools with their GTCEu variants.
- Fixed GTCEu axe, hoe, shovel and scythe behavior, maybe something else, I forgot (reminder: I fixed this in the mod myself, the dev doesn't give a damn).
- Added latex decrafting into rubber in the separator.
- Ore in each rock type now has its own dust, e.g. Gabbro dust, which decrafts into some elements — very little, but something.
- Changed ore localization keys.
- Removed some block tags that are no longer needed.
- Rewrote seemingly all the needed vanilla recipes, and hid all unneeded vanilla items.
- Additionally hid some mechanical TFC items and blocks I forgot about in the last patch.
- Added file and butcher's knife recipes to the anvil recipes.
- Added many recipes for TFC wood and stone in GT machines.
- Added transformation recipes using the AE2 entropy manipulator.
- Fixed an AE2 press recipe bug.
- Removed AE2 cable dyeing recipes using primitive dyes.
- Optimized AE2 cable dyeing recipes.
- Fixed the primitive pump recipe.
- Possibly something else, but I forgot about it.
- Removed wooden head recipes for electric tools (the Greg devs messed up again).
