### Bug fixes
- Fixed a bug where metal could be duplicated via armor, plates, rods and more.
- Fixed a bug where regular iron ingots couldn't be melted into iron.
- Fixed a bug where the coke oven couldn't be crafted because it used regular iron parts; it now uses wrought iron.
- Added new heating recipes for clay ingots for the coke oven.
- Plates are now unified under the sheets and plates tags.
- Fixed a bug where coal and its raw variants couldn't be used in the firepit (some of them don't work, or only work in the blast furnace and campfire — that's intended).
- Coke can now be used as fuel in TFC.
- Fixed a bug where Goethite couldn't be smelted into iron.
- Pumpkins can now be cut into pieces with a knife; the hammer recipe remains as well.
- Fixed all Forge Hammer recipes.
- Added AlloySmelter and Solidifier recipes for crafting TFC anvils.
- Fixed a bug where recipes for gold ingots and others weren't displayed.
- Removed the crafting/decrafting recipes for the vanilla anvil and hid it.
- Removed recipes related to the TFC Primitive Blast Furnace.
- Removed recipes related to the wooden barrel.
- Removed recipes related to FireBricks.
- In short, about a billion more recipes were removed — I'm tired of listing them.
- Fixed backpack recipes (dyeing doesn't work, it's a mod bug).
- Fixed paper recipes.
- Fixed PlantBall recipes.
- Fixed Biomass recipes.
- Fixed glass crafting via the TFC mechanic.
- The tap can no longer be placed on a wood block you placed yourself.
- Added forging for the file and butcher's knife tool heads.
- Added flour processing recipes in the crusher.
- Added a Russian translation for Greg.
- Added/changed a number of quests.
- The Greg dev has crooked hands, so we fixed GT tool usage on TFC blocks ourselves.
- Changed the latex tap recipe.
- Changed the ItemFrame and GlowingItemFrame recipes.
- Removed vanilla bucket recipes using regular iron (crafting recipes will come later).
- Changed the painting recipe.
- Changed the saddle recipe.
- Changed the Repeater and Comparator recipes.
- **TFC changes:**
- Added water wheels, windmills, axles, gearboxes, encased axles and clutches for every TFC wood type.
- Querns can now be connected to a rotating axle for automatic grinding.
- Added a crankshaft that can be connected to bellows for automation.
- Added steel pipes and a steel pump capable of moving multiple source blocks of water, salt water and spring water.
- Added a Jackhammer that can be used to automatically process certain items on an anvil.
- Added new pages to the field guide explaining how to use all the new mechanics.
- Removed the crafting and upgrade recipes for the vanilla bucket.
- Blue and red steel buckets can no longer move sources, and both can carry lava and water-like fluids.
- Fixed many inconsistencies between salt and fresh water caused by the new FORGE FLUID-API (#2542)
- Fixed a bug where bubbles didn't appear while bobbing in salt water.
- Fixed a bug where the "enter water" sound played when moving between salt and fresh water — this fixes the annoying fish noise in rivers.
- Fixed a bug where being underwater in salt water had a different fog effect and was missing ambient sounds.
- Fixed a bug where salt water pushed harder than fresh water.
- And more...
- Fixed several cases where sandwiches, soups or salads wouldn't stack even though they were created in similar/identical situations.
- Fixed a bug where JEI showed a "Never Decay" tooltip which could be confusing (#2560).
- Fixed a compatibility issue where moderators were doing weird things when setting up the creative mode tab.
- Fixed a conflict with Patchouli versions > 81.
- Fixed some typos in the field guide.
- **GTCEu changes:**
- Added the electric substation.
- Added the ore vein diagram.
- Added the fluid vein diagram.
- Added artificial compass pages for all tools.
- Fixed the ore processing diagram.
- Fixed distillery recipes.
- Fixed High Power Casing recipes.
- Fixed a performance issue when rendering wire and pipeline elements.
- Fixed the missing covers texture.
- Fixed a bug where empty/equal barrels couldn't be stacked (affected items need to be placed and broken once).
- Always enable the VBO cache for multi-previews + added a config option to disable it.
