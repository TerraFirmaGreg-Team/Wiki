### Bug fixes
- The pack now uses the latest Forge 47.2.6.
- Fixed recipes related to TFC metal sheets; they all now use the GT plate variant.
- Fixed a bug where stone tools dug faster than metal ones. Also fixed some tool durability issues.
- On first game launch, an explanation text about the password is now shown, since it was scaring some users.
- Multiple changes to early-game GT recipes.
- Partially added starter quests for TFC.
- Due to the switch of the teams mod, fixed a bug where you would get kicked out of your team on a server.
- Added a Mortar recipe to the centrifuge.
- Fixed the Jacks recipe.
- Fixed the metal for cassiterite.
- Added a metal for chalcopyrite.
- Removed useless buttons from the pause menu.
- Fixed the MMC pack.
