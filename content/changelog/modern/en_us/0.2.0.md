### Changes
- Fixed bugs where some items containing metal couldn't be heated.
- Fixed a bug where some TFC items couldn't be heated.
- Rewrote WaterFlasks recipes.
- Rewrote ToolBelt recipes.
- Removed the Sylvite vein.
- Rewrote all AE2 recipes (thanks FriendlyCube).
- Rewrote all AE2WTLib recipes (thanks FriendlyCube).
- Added TFC fertilizer stats to many GT items — they can now be used to fertilize soil instead of Sylvite.
- Fixed multiple issues with forging, welding and heating recipes.
- Fixed a bug where wrought iron items could be re-smelted into wrought iron.
- Added decrafting recipes from TFC fish into fish oil.
- Added decrafting recipes from TFC seeds into seed oil.
- Fixed all torch recipes — they no longer burn forever.
- Fixed a bug where the knife disappeared in pumpkin-cutting recipes.
- Added a mod to view screenshots from chat right in game.
- Rewrote the Exposure mod recipes.
- Rewrote the MoreRed mod recipes.
- Added decrafting recipes for TFC salt water.
- Added mold recipes in the furnace.
- Added recipes for vanilla string.
- Added welding and forging recipes for ingots in the GT hammer.
- Fixed energy output when using lava in a boiler.
- Machines now explode if fed too high a voltage.
- Machines now explode in the rain (or not).
- Machines now need to be dug up with a special tool.
- Rod crafting in GT machines got harder.
- GT ore processing now yields regular stone instead of per-type stone.
- When ore is dug up with a drill, the blocks are replaced with rhyolite.
- Rewrote the main metal-related FirmaLife recipes.
- A thousand years later, duplicate items in AdAstra and Create (ingots, plates) have been disabled.
- Rewrote the SmallShips mod recipes.
- Rewrote some TFShips mod recipes.
- Removed all AdAstra recipes.
- Removed all ComputerCraft recipes.
- Removed all Create recipes.
- Removed dust tags from TFC powders to avoid confusion.
- Updated Rich Presence to the New Year version.
- Fixed a bug where a quest required the wrong ingot (not tested, but it should have fixed itself after the TFC recipe rewrite).
- Added infinite stone recipes to the Rock Breaker.
- Fixed the brick crushing recipe (it fixed itself).
- Added the vanilla bucket recipe.
- Fixed the Blast Furnace recipe.
- Fixed recipes for all tools.
- A bunch of hidden items and other junk.
- Fixed a bunch of recipes related to crushing ore chunks into powder.
- Possibly something else, can't remember everything.
- Added a gregtech translation. (Thanks SoOvey)
