### Changes
- Removed the Minecraft sea lantern recipe.
- Fixed iron and copper greenhouse recipes; hid blocks of some copper greenhouse.
- Fixed several quests.
- Fixed the recipe for melting raw gold into a gold ingot in furnaces and Create mechanisms.
- Balanced the stats of tools that don't duplicate TFC metals.
- Extensive recipe rework to support GTCEu 1.1.0. Nothing changes for the user in practice, but the code needed a lot of work.
- Player effects are now displayed on the left side of the inventory.
- REI items now avoid the TFC buttons on the right side of the inventory — you can safely click the TFC buttons.
- Raw ore blocks were cut from the game.
- Fixed item grouping into lists in REI.
- Fixed localization for GTCEu extruder molds.
- Added localization strings for REI lists.
- Fixed a bug where a wrought ingot could be cast from CastIron.
- Improved some veins (increased indicator spawn height + rarity changes).
- Fixed the TFC Jacks recipe that conflicted with welding two rods.
- Fixed TFC gem drops from sluicing.
- Hid CC turtles — only the default ones remain.
- Added a nether star recipe (temporary) — it will be removed once the nether is added.
- Removed the erroneous GTCEu rubber dust recipe.
- Removed board plate recipes in the Create saw.
- Fixed conflicting compass recipes.
- Fixed a bug where chests could have a vanilla texture in REI.
- Re-enabled extended debug info.
- Fixed ToolBelt recipes once again.
- Fixed a bug where various TFC metals couldn't be melted.
- Possibly something else — thanks for helping the project grow.
