### Changes
- Fixed vanilla ore chunk textures.
- Fixed dirty dust decraft recipes via Create water fanning.
- Updated the interface.
- Added tool heads for the Spade.
- Added forging for the Spade.
- MiningHammers are now made from 2 ingots, meaning they can be obtained before building an extruder.
- Added more Create water-fanning recipes for GT ore.
- Added more AE2 throw-in-water recipes.
- Fixed a bug where the perfectly forged status on a tool head didn't transfer to the tool itself.
- Fixed AE2 terminal recipes.
- Added 2 new veins, Oilsands and Spodumene — details in the Excel table.
- Updated 5 veins — see the Excel table for the changes.
- Added a fluid vein with fresh water.
- ComputerCraft integration.
- Restored the bone meal recipe in CrushingWheels.
- Hopefully fixed the quests that didn't accept tools properly.
- Added many new Create CrushingWheels and Milling recipes.
- Disabled dust recipes for some metals — they now need to be mixed in the Mixer.
- Changed the creosote board recipe.
- Changed the film recipe from the Exposure mod.
- Added Tin Alloy and Red Alloy metals to TFC — they can now be mixed and cast into a mold.
- Integrated FirmaLife as much as possible (removed stainless steel greenhouse recipes + hid some blocks/fluids) + replaced recipes that used stainless steel (what?).
- Some quest updates.
