### Changes
- **IMPORTANT UPDATE. IDEALLY YOU SHOULD RECREATE YOUR WORLD AND START OVER. IF YOU HAVE ANY ERRORS IN OLD WORLDS, PLEASE DON'T WRITE TO ME.**
- Added many recipes for TFC club tool heads (e.g. crafting and decrafting via GTCEu machines).
- Added many recipes for TFC chisel tool heads (e.g. crafting and decrafting via GTCEu machines).
- Added many recipes for TFC mining hammer tool heads (e.g. crafting and decrafting via GTCEu machines).
- Added many recipes for TFC spear tool heads (e.g. crafting and decrafting via GTCEu machines).
- Reconfigured the metal system (again, and for the last time) — TFC cast_iron is now vanilla iron. In general we got rid of TFC ingots and other junk.
- Added many decrafting recipes for GTCEu dusts and ores into TFC metal.
- Added 4 new extruder shapes.
- Added our own double ingots.
- Fixed gem tool head recipes in the extruder.
- Fixed a bug where ore would sometimes drop an item with an empty tag.
- Fixed recipes that crushed some ingots into nothing in Create machines.
- Fixed recipes involving some empty tools.
- EMI was replaced back with REI (it causes wild freezes when opening the quest menu, has no way to hide categories, and displays some fixed recipes incorrectly). JEI + EMI support is left in the code — if you replace REI with EMI + JEI, item hiding and some other functions will keep working.
- Expanded Laser Engraver recipes.
- Fixed the increased metal output from poor ore.
- Fixed the situation where graphite dust couldn't be obtained at the start of the game — now you can dig up the ore with a hammer to get its crushed variant, then crush it again, wash it and crush it once more to get the powder.
- Added double ingots for Tin Alloy.
- Added a drop of the stone material from ore.
- Fixed a bug where tin alloy items couldn't be melted in a crucible.
- Added recipes processing wheat into straw + wheat grains with a chance output.
- Fixed the recipe conflict between dirt and fertilizer.
- Glass can now be cast into kaolinite blocks, just like brass ones.
- Fixed the coke oven brick recipe.
- Fixed tool bugs (probably) — if something doesn't work for you, **PLEASE CREATE A NEW WORLD AND TEST IN A NEW WORLD**.
- Possibly something else I forgot about.
