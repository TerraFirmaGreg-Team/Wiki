### Changes
- Removed bronze steam machines from the game, since they allowed skipping a lot of TFC progression.
- Added a lot of quests for the Primitive age (no descriptions for now).
- Added dyeing recipes for concrete, wool, beds and more.
- Removed the bed recipe using wool blocks.
- Removed the leather recipe from rabbit hide.
- Added metal units to pure iron (dust, blocks, ore, etc).
- Added integration of GT machines with the TFC Ambiental mod.
- Fixed a bug where the knife took no damage while digging grass blocks.
- Fixed a bug where you couldn't start making a FirmaCiv boat because of the GTCEu axe.
- FirmaCiv now uses the GTCEu copper bolt instead of its own.
- Integration of Create, Create Additions and Create Steam and Rails.
- FirmaCiv mod integration.
- Chisel And Bits mod integration.
- Lots of new recipes related to baking dough and producing bread via GTCEu machines.
- New progression recipes (new recipe for ULV and LV GTCEu circuits).
- Removed block-combining recipes in the compressor.
- Removed all ore veins from GTCEu (we use the TFC system anyway, plus optimization).
- New ore textures taken from 1.12.
- Script code improvements and optimizations.
- More blocks and items were sorted into separate lists in REI.
- Fixed FirmaCiv boat(s) creation.
- GTCEu ores can now collapse and break when collapsing, after which they drop a piece of ore.
- Slabs, stairs, walls and other blocks can now collapse.
- Added poor and rich ore chunks with their processing.
- And a lot more that I forgot.
