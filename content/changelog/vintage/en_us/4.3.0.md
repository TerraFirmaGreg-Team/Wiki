### Modpack fixes
- Everyone still playing on old versions of the build, 2.x.x and 3.x.x, can now safely update starting from this version; worlds are automatically converted to the new format without losing progress, but you will not be able to go back.
- Minor fixes to quest descriptions.
- Added a primitive bed quest to help newcomers.
- Fixed the main menu; there will no longer be double logos on first launch.
- Fixed the firmalife door recipe in the assembler.
- Some mods were removed, as their functionality is now in UniversalTweaks.
- Fixed the planet flight bug on servers yet again.
- Fixed textures in TFG-Resourcepacks.
- Something else that we did but forgot.
