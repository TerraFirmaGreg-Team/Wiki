### Changes
- Removed the TFC Medicinal mod — deadly disease will no longer haunt you.
- Removed a fair number of mods that are no longer needed or whose functionality is now covered by other mods.
- Some of the CT scripts have been moved into our TerraFirmaGreg-Core mod.
- Disabled the storage P2P tunnel from the NAE2 mod. #261
- Added a recipe for the AE2 inverted_toggle_bus. #245
- Fixed a bug where some trees had no saplings. #177
- Added a preliminary fix for the crash that occurred when leaving a server.
- Removed the extra clay types added by TFCFlorae — only one remains. The corresponding items and blocks will be removed.
