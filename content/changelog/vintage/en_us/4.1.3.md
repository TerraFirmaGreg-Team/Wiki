#### [Normal, Huge]
### Modpack fixes
* The primitive pump now extracts fresh water instead of salt water.
* Some TFGMod code related to TFCAmbiental has been moved into TFCAmbiental itself, since a fork exists.
* Copper items are now generated via TFGMod.
* Huge optimization of TFGMod UnmoldRecipe recipes; the same was done for TFCFlorae recipes.
* Changed the item generation system via TFGMod.
* Changed the tool generation system via TFGMod.
* You now get a wrought iron ingot from GTCEu straight out of a bloom (you no longer need to reforge ingots 3 times).
* Generation of the 2x ingot + hammer = plate recipes has been disabled via TFGMod.
* Replaced the graves mod with a fork of the same one, but without all the magic stuff that had to be disabled — just a grave and a key.
* OptiFine now loads automatically before the game starts loading.
* The patched version of Chisel is no longer needed; you may need to delete the patched version after updating.
* Fixed a bug where some LT door types would not open.
* Fixed a recipe dupe where the same plant was used for the same TFC-Medicinal extract.
* Any stone bricks are now used to craft xtones zoea.
* All items created by ContentTweaker have been moved to TFG-mod.
* Fixed the T6 alloy recipe for rockets.
* Removed a duplicate rocket stabilizer recipe.
* Clouds lowered slightly, down to height 255; wind speed made lower.
* Teleporting to a grave is now only possible within a 64-block radius, without using an ender pearl.
* Almost all resource files were moved to TFG-mod, which made downloading from Curseforge faster.
* Many TFC texture changes; they were ported from version 1.18.
* Changed quests due to items being moved from ContentTweaker to TFG-mod.
* Changed AE cell recipes due to items being moved from ContentTweaker to TFG-mod.
* Changed recipes for landing modules, ultra-durable plates, and rocket parts due to items being moved from ContentTweaker to TFG-mod.
* Changed recipes for the extruder shape for scythe and knife heads due to items being moved from ContentTweaker to TFG-mod.
* Changed the salt drying recipe due to items being moved from ContentTweaker to TFG-mod.
* The items below will disappear due to the move from ContentTweaker to TFG-mod.
    Bucket of salt
    Extruder Shape (Scythe)
    Extruder Shape (Knife)
    Landing modules tiers 1-3
    Rocket hulls tiers 1-6
    Heavy-duty alloys tiers 1-6
    Rocket computers tiers 1-6
    Empty schematic for rockets
    Fluid casing
* Added a seconds counter to the loading screen.
* The ProjectRed board is made from any stone.
* Stargate mixtures are now made in 5s instead of 50s.
* Changed the crafting of AE paintballs; they are now made similarly to cables.
* Crafting cells using 4 components of the previous tier is now 2 times faster and uses 2 processors instead of 4.
* Added a crafting recipe for the TFCFlorae crate; it was also added to quests.
* Only food and items that can be melted inside can now be put into a vessel.
* Little Backpack recipe fix.
* The moon is now researched by default.
* Removed TFCPaths; it worked poorly.
* Increased the regen chance of stones and sticks on the ground; a problem was observed with this.
* Ores in different rocks are hidden; one instance of each is left.
* Fixed the air extraction recipe on Jupiter.
* Added a crafting recipe for the GC turret.
* Expanded the drop replacement list for breaking vanilla items.
* Added crafting recipes for Aunis symbol crystals.
* Added a crafting recipe for the Aunis portable ancient device.
* Added a crafting recipe for growing the white Aunis crystal.
* Added a crafting recipe for heat-resistant padding tiers 1-4.
* Added/changed the crafting recipe for heat-resistant fabric tiers 1-4.
* Removed a duplicate parachute recipe.
* Removed duplicate recipes for GC loaders and unloaders.
