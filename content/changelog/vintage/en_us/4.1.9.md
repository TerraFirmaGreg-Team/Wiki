### Modpack fixes
- New Year decoration (o^▽^o)
- Some optimization mods were removed and replaced with a single one, UniversalTweaks, which has the same fixes built in.
- The electric greenhouse has been completely replaced with the GTFO analog; the old greenhouse controller will disappear from your world, and the new greenhouse can use different soil, not only the one shown in JEI.
- Added fertilizer quests.
- The modpack freshness line is now taken by a parser from the Git json tag.
- Updated the Darkness mod; previously there was an fps drop when looking at the sky — this is fixed.
- Reduced the number of mobs per player; this should help performance. If you see too few mobs, let us know. 140 -> 30 per player.
- Removed RealBench; it is no longer needed since the engineering station was fixed in the GT update.
- Removed ModularPowersuits and Numina for now; they will possibly be added back with GCYS.
- Removed Gregification; there is an initialization error with the new GT version.
- Changed item Tooltips; they now show different styling for items depending on tier and rarity. More items will be covered in the next updates.
- Enabled vanilla weather rules for Weather2; barrels now fill up in the rain again.
- Removed the recipe for breaking fireclay bricks back into clay, which fixed a dupe.
