### Modpack fixes
- Many scripts were ported from ZenScript to GroovyScript; it is recommended to install the modpack from scratch, saving your world, map, and everything you need beforehand.
- Fixed a bug with tools, where they could not be used in TFC mechanics after the slightest damage.
- JEI recipe transfer now prefers using an existing item in the ME network.
- Added a split-mode button, allowing items and fluid to be inserted into the same side or not.
- In AE, fixed a configured interface item not being displayed if the amount is greater than 128.
- New cell models.
- Fixed many errors with AE2 and OC recipes.
- Fixed missing electric tool recipes.
- Fixed an error when opening the GT central monitor interface.
- Fixed the inability to process some plates in GT machines.
- Fixes to the greenhouse quest.
- Fix to the sugar cane quest.
- Removed quests that are not used.
- The "infinite water" upgrade quest was moved to another branch.
- Fixed the electric tool display.
- The resource pack now has a single name, so you don't have to re-enable it every time after updating.
- Fixed a permissions error when using FTB utilities.
- The improved TFCFlorae textures were moved from the resource pack into the modpack.
- Disabled the "back/home" commands.
- Minimum and maximum rtp distance increased to 10000 and 50000 respectively.
- Added some more missing TFCFlorae textures.
- All OC recipes were moved to scripts and completely rewritten.
- Fixed the sky rendering bug with Astral Sorcery again.
- Enabled Lua54 usage for OC.
