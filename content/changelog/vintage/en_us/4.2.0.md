### Modpack fixes
- **Warning**
- **When updating to this version, all GregTech tools will disappear, as well as wireless terminals from AE2WTLib addons.**
- Another big change: all the custom textures that were used before, as well as music and something else, are now moved into a separate resource pack. By default it is already in your resourcepacks folder; you can enable or disable it as you wish.
- Moved crafttweaker scripts Utility\JEI\AppliedEnergistics2 to groovy.
- Moved crafttweaker scripts Utility\JEI\JEI-Other to groovy.
- Removed AE2WTLib scripts for AE wireless terminals.
- Added recipes for the new AE2 wireless terminals.
- Removed and hid the fluidcrafter block recipe from aeadditions; use the alternative block from the ae2fc mod, its functionality is much broader.
- Added a recipe for the fluid assembler from ae2fc.
- Changed the seed OreDictionary <ore:listAllSeeds> -> <ore:allSeeds>
- Fixed crafting leather in the mixer; the leather output is now the same as in the barrel.
- Adjusted quests due to changes in GregTech. You will need to redo the quests related to tools, as well as the AE2 wireless terminals.
- Another attempt to fix duplicated planets on the star map.
- Fixed the player getting stuck in subspace when flying to another planet, once again.
- Added crushing-to-dust recipes for charged and fluix crystals.
- Fixed a game crash when a tool/item was not fully broken.
- Fixed a game crash when switching the sorting mode in the AE2 terminal.
- Added a recipe for the ProjectRed multichannel cable.
- Removed Simple Login from the public server package; if you need it for authorization, install it manually.
- The Inventory Bogo Sorter mod was removed; it has too many problems for now. It will be replaced by the sorting feature from the Quark mod.
- Added the Quark mod with most features enabled; their list will be adjusted later as needed.
