# 更新与重装整合包

更新整合包时，**完全重装**始终是最安全的方式。 如果你的启动器有“更新”按钮，它通常无法正确更新本整合包，导致配方损坏、游戏无法启动或其他问题。

如果你的整合包出现了别人都没有的奇怪 bug，**完全重装**通常能解决问题。 在[向我们报告](https://github.com/TerraFirmaGreg-Team/Modpack-Modern/issues)之前，先试试这个方法是个好主意。

## 如何完全重装

### Prism

1. 点击窗口顶部的“添加实例”按钮。
2. 转到 CurseForge 标签页，下载 TerraFirmaGreg-Modern。
3. 等待整合包下载并安装完成。
4. 如果询问是要创建新实例还是更新，选择**创建实例**。
5. 出现“发现被屏蔽的模组”窗口时，按照提示下载剩余的模组。
6. 下载完成后，选中新实例，点击右侧的“文件夹”按钮。 再选中旧实例，同样操作。 分别进入各自的 `minecraft` 文件夹。

### CurseForge

1. 选中现有实例，点击橙色“开始游戏”按钮旁边带两个箭头的“更改版本”按钮。
2. 确保选中“更新到最新版本”，然后勾选“更新到独立的整合包配置文件”选项。
3. 等待整合包下载并安装完成。
4. 下载完成后，选中新实例，点击右上角的三个点菜单，选择“打开文件夹”。 再对旧实例进行同样操作。

### 后续步骤

1. 将以下文件夹和文件从旧文件夹复制粘贴到新文件夹中：
   - `saves`
   - `xaero`
   - `backups` (可选)
   - `options.txt`
   - `emi.json` (如果存在)
   - `emi.css` (如果存在)
2. 将新实例的最大内存分配改为之前的值（建议 6-8 GB）
3. 正常启动新实例。 删除旧实例前，确认一切运行正常！

## 服务器

1. 从我们的[GitHub](https://github.com/TerraFirmaGreg-Team/Modpack-Modern/releases)下载服务端包并解压。
2. 将新的服务端文件复制到你的服务器中，放到与当前安装目录不同的文件夹里。
3. 将 `saves` 和 `backups`（可选）文件夹从旧实例复制到新实例中，以及其他服务器专属文件（如玩家白名单）。
4. 正常启动新实例。 删除旧实例前，确认一切运行正常！
5. 你的玩家需要使用相同的版本才能连接服务器。 如果他们遇到模组版本不匹配的错误（即使看起来版本号相同），通常表示他们没有正确更新，你应该把这篇指南的链接发给他们。
