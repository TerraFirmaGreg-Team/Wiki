Dragonlib is a library mod needed for Create: Railways Navigator.
Unfortunately simply installing the latest version has been known to cause issues.
# Known working version pairs
The following combinations of Create: Railways Navigator and Dragonlib have been found to work:


| CRN version | Dragonlib Version |
| ----------- | ------------------ |
| forge-1.20.1-beta-0.9.1 ([CF](https://www.curseforge.com/minecraft/mc-mods/create-railways-navigator/files/8175339), [MR](https://modrinth.com/mod/create-railways-navigator/version/r5q4MIYy))| forge-1.20.1-beta-3.0.21 ([CF](https://www.curseforge.com/minecraft/mc-mods/dragonlib/files/7654926), [MR](https://modrinth.com/mod/dragonlib/version/Avd2XMrj)) |
