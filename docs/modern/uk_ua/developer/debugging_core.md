## Налагодження TFGCore за допомогою точок зупинки в екземплярі модпаку

Іноді під час розробки TFGCore може виникнути ситуація, коли поведінка моду в середовищі розробки відрізняється від його поведінки в середовищі модпаку.
Цей посібник пояснює, як підключити налагоджувач до екземпляра Modpack-Modern, щоб отримати необхідні інструменти для налагодження складних проблем.

Джерело інформації: https://www.jetbrains.com/help/idea/attach-to-process.html

### Налаштування

- Май робочий екземпляр [Core-Modern](https://github.com/TerraFirmaGreg-Team/Core-Modern)
- Лаунчер, який дозволяє змінювати аргументи JVM

### Кроки

1. Переконайся, що твій екземпляр модпаку використовує ту саму гілку, що й Core-Modern
- Якщо ти налагоджуєш екземпляр модпаку з гілки dev, Core-Modern також має використовувати гілку dev.
2. Збери TFGCore так, щоб файл .jar опинився в екземплярі твого модпаку. Тобі потрібно налаштувати файл `gradle-local.properties`. Інструкцію з його налаштування знайдеш [тут](https://wiki.terrafirmagreg.team/modern/en_us/developer/datagen)
3. Додай наведені нижче аргументи Java до JVM твого екземпляра модпаку.
```
-agentlib:jdwp=transport=dt_socket,server=y,suspend=y,address=127.0.0.1:5005
```
- `suspend=y` призупиняє виконання модпаку, доки не буде підключено налагоджувач. встанови значення `n` якщо не хочеш такої поведінки
- Знайди аргументи Java у Prism Launcher: клацни правою кнопкою миші по екземпляру модпаку, вибери `Edit`, а потім відкрий вкладку `Settings` на бічній панелі.
  <img width="608" height="532" alt="image" src="https://github.com/user-attachments/assets/dd9e9b4e-8ce4-4f84-90f6-ac293b6f9ad5" />

4. Запусти свій екземпляр модпаку.
5. В IntelliJ відкрий `Run/Attach to Process`
6. Вибери варіант, що містить номер порту 5005
   <img width="650" height="314" alt="image" src="https://github.com/user-attachments/assets/09c76555-abd8-4dc1-bd35-56a06348f9bb" />

7. Це підключить налагоджувач до екземпляра модпаку, після чого модпак запуститься у звичайному режимі
8. Встановлюй точки зупинки в TFGCore, щоб призупиняти виконання коду в момент їх досягнення та мати змогу досліджувати внутрішні процеси.
