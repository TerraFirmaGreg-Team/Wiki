# Автоматизація ME фабрикатор резонансу та ME зарядник резонансу

Автоматизація заміни істинного паростка за допомогою просторових портів введення-виведення Applied Energistics 2 та затримки сигналу в дротах.

Використання простого редстоуну з компонентами MoreRed забезпечує надійний спосіб міняти місцями два різні зароджувальні кристали між MEФР та MEЗР, щоб підтримувати найкоротший час виконання рецептів.

## Вимоги до налаштування

- **Два просторові порти введення-виведення AE2**
- **Дві 2³ просторові комірки сховища AE2**
- **Кабелі з червоного сплаву MoreRed двох різних кольорів**
- **MoreRed - NOT шлюз, AND шлюз, Імпульсний шлюз**
- **Релейна плита для пучка кабелів** або **Пучок кабелів**
- **Кришка контролера машини**
- **Будь-які два маніпулятори**
- **Кілька труб для предметів**
- **Три повторювачі**
- **Редстоуновий смолоскип**

## Розбір логіки

### 1. Сигнал головного реактора (СИНІЙ)

- Використовує затримку сигналу залежно від довжини дроту, щоб активувати логічний елемент `NOT` коли якість падає нижче порогового значення.
- **Сколотий або вище** 2 блоки редстоунового пилу
- **Дефектний або вище** 3 блоки редстоунового пилу.
- **Бездоганний або вище** 4 блоки редстоунового пилу.
- **Вишуканий** 5 блоків редстоунового пилу.

> **Примітка.** Використання стандартного віднімання сигналів компаратора для виявлення блока істинного кварцу може призвести до нескінченних циклів заміни, оскільки 1 - 1 <= 0. Заміна логіки віднімання на затримку сигналу в кабелі з червоного сплаву та використання логічного елемента `NOT` розв'язують цю проблему.

### 2. Сигнал резерву / зарядника (БІЛИЙ)

- Під'єднується від вторинного порту через блокування логічним елементом `AND`, щоб використаний зароджувальний кристал замінювався лише тоді, коли повністю заряджений кристал готовий. Для довжини редстоунового пилу застосуй ту саму логіку, що й для СИНЬОГО дроту.

### 3. Генератор подвійного імпульсу із затримкою

- Додавання генератора імпульсів із двома різними інтервалами повторювачів забезпечує дворазову активацію порту введення-виведення, щоб _забрати_ та _поставити_ блок паросток істинного кварцу.

> **Примітка.** Розмісти два паростки істинного кварцу перед тим, як подавати живлення на редстоунову схему.

### 4. Обертання просторової комірки

Щоб переміщувати просторові комірки сховища між портами:

- Проклади **дві окремі лінії труб для предметів**.
- Витягуй із **нижньої** частини порту A та вставляй у **верхню** частину порту Б.
- Витягуй із **нижньої** частини порту Б та вставляй у **верхню** частину порту А.
- Використовуй маніпулятори в режимі вставлення для подачі предметів у труби.
